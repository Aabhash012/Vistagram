# Vistagram Seed Data Generator:

## Setup:
1. Install Python 3.8+
2. Navigate to the generator:
   ```bash
   cd scripts/data-generation

3. Install dependencies:
    ```bash
   pip install -r requirements.txt
4. Run the generator:   
    ```bash 
    python generate_seed.py
   
5. After generation:
    ```bash
    cp scripts/data-generation/seed-data.json vistagram/src/main/resources/
